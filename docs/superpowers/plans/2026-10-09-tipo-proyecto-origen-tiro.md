# tipoProyecto + Catálogos de Origen y Tiro — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `tipoProyecto` enum to `Frente`, and introduce two new catalogs (`OrigenCatalogo`/`TiroCatalogo`) with per-frente assignment following the exact same pattern as the existing `Material`/`MaterialFrente` system — plus three new mobile API endpoints and a single tabbed admin page.

**Architecture:** The existing `Material` + `MaterialFrente` pattern (global catalog with soft-delete + junction table for per-frente assignment) is replicated verbatim for both `OrigenCatalogo`/`OrigenFrente` and `TiroCatalogo`/`TiroFrente`. A new `TipoProyecto` enum (`LINEAL` | `FIJO`) on `Frente` determines mobile field behavior. Three new mobile endpoints (`/api/mobile/frentes`, `/api/mobile/origenes`, `/api/mobile/tiros`) follow the same auth + role-based filtering pattern as `/api/mobile/materials`. The web admin UI is a single page at `/origen-destino` with two tabs (Orígenes / Tiros), each showing the catalog + frente assignment panels.

**Tech Stack:** Next.js 14 App Router, Prisma ORM (PostgreSQL), NextAuth + custom JWT (mobile), Zustand, shadcn/ui + Tailwind CSS, Jest

## Global Constraints

- All UI strings must go through `white-label.config.ts` (add new keys under `ui.origenes`, `ui.tiros`, `ui.navbar`).
- All server actions require `owner` role — use `getAppUser()` from `@/auth/auth.user`.
- All mobile endpoints use `TokenAuthenticator` from `@/auth/TokenAuthenticator` for Bearer token auth.
- Role-based frente access: `owner`/`general` → all frentes; `admin`/`user` → only assigned frentes via `UserFrente`.
- Import paths use `@/*` alias for `src/*`.
- White-label string access for new keys uses `(whiteLabelConfig as any)?.ui?.origenes?.xxx || "fallback"` pattern (same cast pattern already in use for materials).
- `OrigenCatalogo` and `TiroCatalogo` do **NOT** have `normalizedNombre` — unlike `Material`, they don't need normalization for matching at ingestion time.
- Do NOT migrate existing `origen`/`destino` free-text values in `VoucherCamion` — leave as-is.
- Follow the Git workflow: branch from `dev`, never push to `main` directly.

```javascript
/**
 * Seed the global OrigenCatalogo. Run once:
 *   node prisma/seeders/seed-origenes.js
 *
 * Optionally assign all origenes to every existing frente:
 *   node prisma/seeders/seed-origenes.js --assign
 */
const { PrismaClient } = require("@prisma/client");
const prisma = new PrismaClient();

const DEFAULT_ORIGENES = [
  "Banco de Material",
  "Banco de Préstamo",
  "Préstamo Lateral",
  "Cantera",
  "Mina",
  "Planta",
  "Demolición",
  "Despalme",
  "Otro",
];

async function main() {
  const shouldAssign = process.argv.includes("--assign");

  console.log("Seeding global origen catalog...");

  const origenes = [];
  for (const nombre of DEFAULT_ORIGENES) {
    const origen = await prisma.origenCatalogo.upsert({
      where: { nombre },
      update: {},
      create: { nombre },
    });
    origenes.push(origen);
  }

  console.log(`Seeded ${origenes.length} origenes in catalog.`);

  if (shouldAssign) {
    const frentes = await prisma.frente.findMany();
    console.log(`Assigning origenes to ${frentes.length} existing frentes...`);

    for (const frente of frentes) {
      for (const origen of origenes) {
        await prisma.origenFrente.upsert({
          where: {
            frenteNombre_origenId: {
              frenteNombre: frente.nombre,
              origenId: origen.id,
            },
          },
          update: {},
          create: {
            frenteNombre: frente.nombre,
            origenId: origen.id,
          },
        });
      }
    }

    console.log("Assigned default origenes to all frentes.");
  }

  console.log("Done.");
}

main()
  .catch((e) => {
    console.error(e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

- [ ] **Step 3: Implement origenes.ts**

Create `src/actions/origenes.ts`. This is a direct replica of `src/actions/materials.ts`, replacing `Material`/`material` with `OrigenCatalogo`/`origen`, and removing `normalizedNombre` logic:

```typescript
"use server";

import prisma from "@/lib/db";
import { getAppUser } from "@/auth/auth.user";

// --- Catalog Actions ---

export async function getOrigenes() {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  return prisma.origenCatalogo.findMany({
    orderBy: { nombre: "asc" },
    select: { id: true, nombre: true, isActive: true, createdAt: true },
  });
}

export async function createOrigen(nombre: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const trimmed = nombre.trim();
  if (!trimmed) {
    throw new Error("El nombre del origen no puede estar vacío");
  }

  const existing = await prisma.origenCatalogo.findUnique({
    where: { nombre: trimmed },
  });

  if (existing) {
    if (existing.isActive) {
      throw new Error(`Ya existe un origen con ese nombre: "${existing.nombre}"`);
    }
    return prisma.origenCatalogo.update({
      where: { id: existing.id },
      data: { isActive: true },
      select: { id: true, nombre: true, isActive: true },
    });
  }

  return prisma.origenCatalogo.create({
    data: { nombre: trimmed },
    select: { id: true, nombre: true, isActive: true },
  });
}

export async function renameOrigen(id: string, newNombre: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const trimmed = newNombre.trim();
  if (!trimmed) {
    throw new Error("El nombre del origen no puede estar vacío");
  }

  const conflict = await prisma.origenCatalogo.findFirst({
    where: { nombre: trimmed, NOT: { id } },
  });
  if (conflict) {
    throw new Error(`Ya existe un origen con ese nombre: "${conflict.nombre}"`);
  }

  return prisma.origenCatalogo.update({
    where: { id },
    data: { nombre: trimmed },
    select: { id: true, nombre: true, isActive: true },
  });
}

export async function deactivateOrigen(id: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  await prisma.$transaction([
    prisma.origenFrente.deleteMany({
      where: { origenId: id },
    }),
    prisma.origenCatalogo.update({
      where: { id },
      data: { isActive: false },
    }),
  ]);

  return { success: true };
}

// --- Frente Assignment Actions ---

export async function getFrenteOrigenes(frenteNombre: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const [assigned, allActive] = await Promise.all([
    prisma.origenFrente.findMany({
      where: { frenteNombre },
      include: { origen: { select: { id: true, nombre: true } } },
      orderBy: { origen: { nombre: "asc" } },
    }),
    prisma.origenCatalogo.findMany({
      where: { isActive: true },
      select: { id: true, nombre: true },
      orderBy: { nombre: "asc" },
    }),
  ]);

  const assignedIds = new Set(assigned.map((a) => a.origenId));

  return {
    assigned: assigned.map((a) => a.origen),
    available: allActive.filter((o) => !assignedIds.has(o.id)),
  };
}

export async function assignOrigenToFrente(
  origenId: string,
  frenteNombre: string
) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const origen = await prisma.origenCatalogo.findUnique({
    where: { id: origenId },
  });
  if (!origen || !origen.isActive) {
    throw new Error("El origen no existe o está inactivo");
  }

  const frente = await prisma.frente.findUnique({
    where: { nombre: frenteNombre },
  });
  if (!frente) {
    throw new Error("El frente no existe");
  }

  await prisma.origenFrente.create({
    data: { origenId, frenteNombre },
  });

  return { success: true };
}

export async function unassignOrigenFromFrente(
  origenId: string,
  frenteNombre: string
) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
```

```typescript
"use server";

import prisma from "@/lib/db";
import { getAppUser } from "@/auth/auth.user";

// --- Catalog Actions ---

export async function getTiros() {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  return prisma.tiroCatalogo.findMany({
    orderBy: { nombre: "asc" },
    select: { id: true, nombre: true, isActive: true, createdAt: true },
  });
}

export async function createTiro(nombre: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const trimmed = nombre.trim();
  if (!trimmed) {
    throw new Error("El nombre del tiro no puede estar vacío");
  }

  const existing = await prisma.tiroCatalogo.findUnique({
    where: { nombre: trimmed },
  });

  if (existing) {
    if (existing.isActive) {
      throw new Error(`Ya existe un tiro con ese nombre: "${existing.nombre}"`);
    }
    return prisma.tiroCatalogo.update({
      where: { id: existing.id },
      data: { isActive: true },
      select: { id: true, nombre: true, isActive: true },
    });
  }

  return prisma.tiroCatalogo.create({
    data: { nombre: trimmed },
    select: { id: true, nombre: true, isActive: true },
  });
}

export async function renameTiro(id: string, newNombre: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const trimmed = newNombre.trim();
  if (!trimmed) {
    throw new Error("El nombre del tiro no puede estar vacío");
  }

  const conflict = await prisma.tiroCatalogo.findFirst({
    where: { nombre: trimmed, NOT: { id } },
  });
  if (conflict) {
    throw new Error(`Ya existe un tiro con ese nombre: "${conflict.nombre}"`);
  }

  return prisma.tiroCatalogo.update({
    where: { id },
    data: { nombre: trimmed },
    select: { id: true, nombre: true, isActive: true },
  });
}

export async function deactivateTiro(id: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  await prisma.$transaction([
    prisma.tiroFrente.deleteMany({
      where: { tiroId: id },
    }),
    prisma.tiroCatalogo.update({
      where: { id },
      data: { isActive: false },
    }),
  ]);

  return { success: true };
}

// --- Frente Assignment Actions ---

export async function getFrenteTiros(frenteNombre: string) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const [assigned, allActive] = await Promise.all([
    prisma.tiroFrente.findMany({
      where: { frenteNombre },
      include: { tiro: { select: { id: true, nombre: true } } },
      orderBy: { tiro: { nombre: "asc" } },
    }),
    prisma.tiroCatalogo.findMany({
      where: { isActive: true },
      select: { id: true, nombre: true },
      orderBy: { nombre: "asc" },
    }),
  ]);

  const assignedIds = new Set(assigned.map((a) => a.tiroId));

  return {
    assigned: assigned.map((a) => a.tiro),
    available: allActive.filter((t) => !assignedIds.has(t.id)),
  };
}

export async function assignTiroToFrente(
  tiroId: string,
  frenteNombre: string
) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  const tiro = await prisma.tiroCatalogo.findUnique({
    where: { id: tiroId },
  });
  if (!tiro || !tiro.isActive) {
    throw new Error("El tiro no existe o está inactivo");
  }

  const frente = await prisma.frente.findUnique({
    where: { nombre: frenteNombre },
  });
  if (!frente) {
    throw new Error("El frente no existe");
  }

  await prisma.tiroFrente.create({
    data: { tiroId, frenteNombre },
  });

  return { success: true };
}

export async function unassignTiroFromFrente(
  tiroId: string,
  frenteNombre: string
) {
  const user = await getAppUser();
  if (!user || user.role !== "owner") {
    throw new Error("No autorizado");
  }

  await prisma.tiroFrente.delete({
    where: {
      frenteNombre_tiroId: { tiroId, frenteNombre },
    },
  });

  return { success: true };
}
```

Create `src/app/api/mobile/tiros/route.ts`. Same pattern as origenes, replacing `origenFrente`→`tiroFrente`, `origen`→`tiro`, `origenes`→`tiros`:

```typescript
import { NextRequest, NextResponse } from "next/server";
import prisma from "@/lib/db";
import { TokenAuthenticator } from "@/auth/TokenAuthenticator";

export const dynamic = "force-dynamic";

export async function GET(req: NextRequest) {
  try {
    const authHeader = req.headers.get("authorization");
    const accessToken = authHeader && authHeader.split(" ")[1];

    if (!accessToken || !TokenAuthenticator.verify(accessToken)) {
      return NextResponse.json(
        { error: "No autorizado, proporcione credenciales válidas para realizar esta acción" },
        { status: 401 }
      );
    }

    const decoded = TokenAuthenticator.decode(accessToken);
    if (!decoded) {
      return NextResponse.json({ error: "Token inválido" }, { status: 401 });
    }

    let frenteNombres: string[];

    if (decoded.role === "owner" || decoded.role === "general") {
      const frentes = await prisma.frente.findMany({
        select: { nombre: true },
      });
      frenteNombres = frentes.map((f) => f.nombre);
    } else {
      const userRecord = await prisma.user.findUnique({
        where: { username: decoded.username },
        include: { frentes: true },
      });
      frenteNombres = userRecord?.frentes.map((f) => f.frenteNombre) ?? [];
    }

    const assignments = await prisma.tiroFrente.findMany({
      where: {
        frenteNombre: { in: frenteNombres },
        tiro: { isActive: true },
      },
      include: {
        tiro: { select: { nombre: true } },
      },
      orderBy: { tiro: { nombre: "asc" } },
    });

    const tiros: Record<string, string[]> = {};
    for (const frenteNombre of frenteNombres) {
      tiros[frenteNombre] = [];
    }
    for (const assignment of assignments) {
      tiros[assignment.frenteNombre].push(assignment.tiro.nombre);
    }

    return NextResponse.json({ tiros });
  } catch (error) {
    console.error("Error al obtener tiros:", error);
    return NextResponse.json(
      { error: "Error interno del servidor" },
      { status: 500 }
    );
  }
}
```
